# คู่มือการใช้งานระบบ CertiFlow (สำหรับ Admin และ Staff)

คู่มือนี้อธิบายวิธีใช้งานหน้า **Management Mode** ของระบบ CertiFlow ตั้งแต่เข้าสู่ระบบไปจนถึงการออกเกียรติบัตรและตรวจสอบข้อมูล เนื้อหาเดียวกันนี้เปิดดูได้จากภายในระบบเองที่เมนู **"คู่มือการใช้งาน"** เมื่อ login แล้ว

---

## สิทธิ์การใช้งาน: ADMIN กับ STAFF ต่างกันอย่างไร

| เมนู/ฟังก์ชัน | ADMIN | STAFF |
|---|---|---|
| ภาพรวม (Dashboard) | ✅ | ✅ |
| จัดการกิจกรรม (สร้าง/แก้ไข) | ✅ | ✅ |
| ลบกิจกรรม | ✅ | ❌ |
| นำเข้ารายชื่อ / แก้ไขผู้เข้าร่วม | ✅ | ✅ |
| ออกเลข / แก้ไข / revoke / reissue เกียรติบัตร | ✅ | ✅ |
| ลบเกียรติบัตร (เฉพาะที่ยังไม่ออกเลข) | ✅ | ❌ |
| ตั้งค่าระบบ (Settings) | ✅ | ❌ (มองไม่เห็นเมนูนี้เลย) |
| จัดการผู้ใช้งาน (สร้าง/ปิดบัญชี) | ✅ | ❌ |
| ดู Audit Logs / รายงานปัญหาจากสาธารณะ | ✅ | ❌ |

โดยสรุป: **STAFF ทำงานประจำวันได้ครบ** (สร้างกิจกรรม, นำเข้ารายชื่อ, ออกเลข, แก้ไข/ยกเลิกเกียรติบัตร) ส่วนงานที่กระทบความปลอดภัยของระบบหรือลบข้อมูลถาวร (ลบกิจกรรม/เกียรติบัตร, ตั้งค่าระบบ, จัดการผู้ใช้) สงวนไว้ให้ **ADMIN** เท่านั้น

---

## เข้าสู่ระบบ

1. เปิดหน้าเว็บ CertiFlow แล้วกดปุ่ม **"Management Mode"** มุมขวาบน
2. กรอก userId และรหัสผ่านที่ได้รับจาก ADMIN
3. หากพิมพ์รหัสผ่านผิดเกิน 5 ครั้งติดต่อกัน ระบบจะล็อกชั่วคราว 15 นาที (ป้องกันการเดารหัสผ่าน)
4. เมื่อ login สำเร็จ ระบบจะจำสถานะ login ไว้ในเบราว์เซอร์ (session) — ปิดแท็บแล้วเปิดใหม่ยังคง login อยู่ จนกว่าจะกด "ออกจากระบบ" หรือ session หมดอายุ (6 ชั่วโมง)

---

## 1. ภาพรวม (Dashboard)

หน้าแรกหลัง login แสดงสรุปภาพรวมทั้งระบบ:

- **กิจกรรมทั้งหมด / ผู้เข้าร่วมทั้งหมด** — จำนวนสะสมทุกกิจกรรม
- **ออกเกียรติบัตรแล้ว** (สีทอง) — จำนวนใบที่มีเลขที่แล้ว สถานะ ISSUED
- **รอดำเนินการ** — ใบที่ยังไม่ได้ออกเลข (DRAFT/PENDING)
- **ถูกยกเลิก (Revoked)** — ใบที่ถูกยกเลิกแล้ว
- ตารางด้านล่างสรุปยอดแยกตามแต่ละกิจกรรม พร้อมสถานะกิจกรรม (DRAFT/ACTIVE/CLOSED)

กดปุ่ม **"รีเฟรชข้อมูล"** เพื่อดึงตัวเลขล่าสุด

---

## 2. จัดการกิจกรรม (Activities)

### สร้างกิจกรรมใหม่

กดปุ่ม **"+ สร้างกิจกรรมใหม่"** แล้วกรอกข้อมูล:

| ฟิลด์ | คำอธิบาย |
|---|---|
| ชื่อกิจกรรม / ผู้จัด / หน่วยงานที่ออก | ข้อมูลแสดงในหน้าค้นหาและใบเกียรติบัตร |
| วันที่เริ่ม / วันที่สิ้นสุด / วันที่ออกใบเกียรติบัตร | เลือกจากปฏิทิน (คลิกที่ช่องแล้วเลือกวันที่) |
| ข้อความนำหน้า / ชื่อย่อ / ปี พ.ศ. / รูปแบบตัวเลข / เลขเริ่มต้น-สิ้นสุด / จำนวนหลัก / ตัวคั่น | กำหนดรูปแบบเลขที่เกียรติบัตร เช่น `เลขที่ สพม.พลอต ๐๐๐๑/๒๕๖๙` |
| Google Slides Template ID | ดู [วิธีเตรียม Template](#เตรียม-google-slides-template) ด้านล่าง |
| ด้านการอบรม | เลือก **ไม่มี** (ค่าเริ่มต้น — เกียรติบัตรไม่ระบุด้านการอบรม) หรือ **มี** ซึ่งจะเปิดกล่องข้อความให้พิมพ์ค่าที่จะใช้แทน `{{type}}` เมื่อไฟล์นำเข้าไม่ได้ระบุด้านการอบรมของคนนั้น |
| สถานะกิจกรรม | DRAFT (ร่าง ยังไม่เปิดค้นหาสาธารณะ) / ACTIVE (เปิดใช้งาน) / CLOSED (ปิดรับ) |

**สำคัญเรื่องเลขที่เกียรติบัตร:**
- ระบบออกเลขให้อัตโนมัติแบบไม่ซ้ำกันเสมอ (ล็อกกันชนกันแม้กดพร้อมกันหลายคน)
- ห้ามลดค่า "เลขเริ่มต้น" ให้ต่ำกว่าที่เคยใช้ไปแล้ว ระบบจะไม่อนุญาตให้บันทึก (ป้องกันเลขซ้ำ)
- ถ้าออกเลขจนถึง "เลขสิ้นสุด" แล้ว ต้องแก้ไขกิจกรรมเพื่อขยายเลขสิ้นสุดก่อนออกเพิ่ม
- **ช่วงเลขห้ามทับซ้อนกันข้ามกิจกรรม** สำหรับกิจกรรมที่ใช้รูปแบบเลขเดียวกัน (ข้อความนำหน้า + prefix + ตัวคั่น + ปี ตรงกันทั้งหมด) ระบบจะปฏิเสธการบันทึกพร้อมบอกว่าไปทับกับกิจกรรมใดและช่วงไหน
  - บันทึกได้: กิจกรรมที่ 1 = 1111-1220, กิจกรรมที่ 2 = 1331-1351 (ช่วงว่างระหว่างกลางไม่เป็นไร ระบบไม่บังคับให้เลขต่อเนื่องกัน)
  - ถูกปฏิเสธ: กิจกรรมที่ 1 = 1111-1220, กิจกรรมที่ 2 = 1200-1300 (ทับกันที่ 1200-1220)
  - ถ้าจำเป็นต้องใช้ช่วงเลขเดียวกันจริงๆ ให้เปลี่ยน prefix / ตัวคั่น / ปี ให้ต่างกัน เพราะเลขที่พิมพ์ออกมาจะไม่ซ้ำกันแล้ว

### เตรียม Google Slides Template

1. สร้างไฟล์ Google Slides ที่มี **สไลด์หลักเพียง 1 หน้า**
2. ใส่ข้อความ `{{name}}` ตรงตำแหน่งที่จะแสดงชื่อผู้รับ และ `{{certNo}}` ตรงตำแหน่งเลขที่เกียรติบัตร (ต้องมีอย่างละ 1 ตำแหน่งเท่านั้น ห้ามซ้ำ)
   - เพิ่มได้อีก 2 ตัวแบบไม่บังคับ: `{{office}}` = สถานศึกษา/หน่วยงานของผู้รับ และ `{{type}}` = ด้านการอบรม (เช่น ด้านการอ่าน, ด้านคณิตศาสตร์) ใส่ได้อย่างละไม่เกิน 1 ตำแหน่งเช่นกัน ถ้าไม่ใส่ในเทมเพลตก็ไม่มีผลใดๆ
3. คัดลอก Template ID จาก URL ของไฟล์ (ส่วนระหว่าง `/d/` กับ `/edit`) มาใส่ในฟอร์ม
4. กด **"ตรวจ Template"** เพื่อให้ระบบเช็คว่าพบ placeholder ครบถูกต้องหรือไม่
5. กด **"Preview"** เพื่อดูตัวอย่างหน้าตาจริงโดยใช้ข้อมูลตัวอย่าง (อาจใช้เวลา 3-8 วินาที เพราะต้องสร้างไฟล์ชั่วคราวและแปลงเป็นรูปจริง)

### แก้ไข / ลบกิจกรรม

- กด **"แก้ไข"** เพื่อเปลี่ยนข้อมูล — แก้ได้แม้มีเกียรติบัตรออกไปแล้ว (ยกเว้นการลดเลขเริ่มต้นตามที่กล่าวข้างต้น)
- กด **"ลบ"** ได้เฉพาะ ADMIN และเฉพาะกิจกรรมที่ยังไม่มีข้อมูลอ้างอิง (ไม่มีผู้เข้าร่วม/เกียรติบัตรผูกอยู่)

## 3. นำเข้ารายชื่อ (Participants)

หน้านี้มีปุ่มนำเข้า 2 ปุ่ม เลือกใช้ตามจำนวนรายชื่อ:

- **"+ เพิ่มทีละรายการ"** — กรอกข้อมูลผู้เข้าร่วมทีละคนผ่านฟอร์ม เหมาะกับการเพิ่มคนตกหล่นภายหลัง
- **"+ นำเข้าจากไฟล์ Excel/CSV"** — นำเข้าทีละหลายรายการจากไฟล์หรือข้อความที่วาง

### วิธีที่ 1 — เพิ่มทีละรายการ

1. กดปุ่ม **"+ เพิ่มทีละรายการ"** (ถ้ากำลังดูรายชื่อของกิจกรรมใดอยู่ ระบบจะเลือกกิจกรรมนั้นไว้ให้อัตโนมัติ)
2. กรอก คำนำหน้า / **ชื่อ*** / **นามสกุล*** / สถานศึกษา-หน่วยงาน / ด้านการอบรม / สถานะ — ช่องด้านการอบรมเว้นว่างได้เช่นเดียวกับการนำเข้าไฟล์
3. หากชื่อ-นามสกุล-สถานศึกษาซ้ำกับรายชื่อที่มีอยู่แล้วในกิจกรรมนั้น ระบบจะเตือน ให้ติ๊กยืนยันแล้วกด "บันทึก" อีกครั้งถ้าต้องการเพิ่มจริง
4. ติ๊ก **"บันทึกแล้วเปิดฟอร์มค้างไว้เพื่อเพิ่มรายถัดไป"** เมื่อต้องการกรอกต่อเนื่องหลายคน — ระบบจะล้างเฉพาะช่องคำนำหน้า/ชื่อ/นามสกุล และคงกิจกรรม สถานศึกษา ด้านการอบรม สถานะเดิมไว้

รายชื่อที่เพิ่มด้วยวิธีนี้ผ่านการตรวจสอบชุดเดียวกับการนำเข้าไฟล์ และสร้าง Certificate สถานะ DRAFT ให้อัตโนมัติเหมือนกัน

### วิธีที่ 2 — นำเข้าจากไฟล์ Excel/CSV

1. กดปุ่ม **"+ นำเข้าจากไฟล์ Excel/CSV"**
2. เลือกกิจกรรมที่จะนำเข้า
3. เลือกวิธีใดวิธีหนึ่ง:
   - **อัปโหลดไฟล์ CSV/XLSX** — กด "ดาวน์โหลด Template Excel" ก่อนเพื่อได้ไฟล์ตัวอย่างที่มีหัวคอลัมน์ถูกต้อง กรอกข้อมูลแล้วอัปโหลดกลับ ระบบจะจับคู่หัวคอลัมน์ให้อัตโนมัติ (รองรับทั้งภาษาไทยและอังกฤษ)
   - **วางข้อความ** — คั่นแต่ละคอลัมน์ด้วยจุลภาคหรือ Tab ตามรูปแบบ `คำนำหน้า, ชื่อ, นามสกุล, โรงเรียน/หน่วยงาน, ด้านการอบรม, สถานะ`
   - คอลัมน์ **"ด้านการอบรม (เว้นว่างได้)"** (ใช้พิมพ์ลง `{{type}}` ในเกียรติบัตร) เว้นว่างได้ตามชื่อ ระบบจะใช้ค่าที่ตั้งไว้ในหน้ากิจกรรมแทน และถ้ากิจกรรมเลือก "ไม่มี" ก็ปล่อยว่างทั้งคอลัมน์ได้เลย ส่วนคอลัมน์ **"โรงเรียน/หน่วยงาน"** ใช้พิมพ์ลง `{{office}}`
   - ไฟล์ Template Excel มีชีต **"คำแนะนำ"** อธิบายทุกคอลัมน์ว่าบังคับกรอกหรือไม่ (ระบบอ่านเฉพาะชีตแรกตอนนำเข้า ชีตคำแนะนำจึงไม่กระทบการนำเข้า)
   - ตารางตรวจสอบก่อนนำเข้าจะแสดงทั้งสถานศึกษาและด้านการอบรมของทุกแถว ถ้าช่องสถานศึกษาขึ้นว่า "— ว่าง —" แปลว่าหัวคอลัมน์ในไฟล์จับคู่ไม่ติด ให้แก้ชื่อหัวคอลัมน์ให้มีคำว่า โรงเรียน/สถานศึกษา/หน่วยงาน หรือ school
4. กด **"ตรวจสอบข้อมูลก่อนนำเข้า (Validate)"** — ระบบจะแยกแถวเป็น 3 กลุ่ม: **ถูกต้อง / อาจซ้ำ (มีชื่อ-นามสกุล-โรงเรียนตรงกับที่มีอยู่แล้ว) / ผิดพลาด** (ขาดชื่อ/นามสกุล หรือสถานะไม่ถูกต้อง)
5. หากมีรายการ "อาจซ้ำ" และต้องการนำเข้าจริงๆ ให้ติ๊ก "ยืนยันนำเข้ารายชื่อที่อาจซ้ำซ้อนด้วย" ก่อนกดยืนยัน
6. กด **"ยืนยันการบันทึกนำเข้า"**

นำเข้าได้สูงสุด 5,000 แถวต่อครั้ง แต่ละแถวที่นำเข้าสำเร็จจะถูกสร้างเป็น Participant + Certificate (สถานะ DRAFT รอออกเลข) โดยอัตโนมัติ

### แก้ไขผู้เข้าร่วมรายคน

เลือกกิจกรรมในตารางหลัก แล้วกด "แก้ไข" ที่แถวนั้น — แก้ชื่อ/นามสกุล/สถานศึกษา/ด้านการอบรม/สถานะได้ (ถ้าเกียรติบัตรออกเลขไปแล้ว ระบบจะบันทึกชื่อเดิมไว้ใน Audit Log อัตโนมัติเมื่อแก้ครั้งแรก)

## 4. รายการเกียรติบัตร (Certificates Registry)

หน้านี้คือทะเบียนกลางของเกียรติบัตรทุกใบ กรองได้ตามกิจกรรม/สถานะ และค้นหาในตารางได้

### วงจรสถานะเกียรติบัตร

```
DRAFT/PENDING ──ออกเลข──> ISSUED ──ยกเลิก (ระบุเหตุผล)──> REVOKED ──ออกใหม่ (คงเลขเดิม)──> DRAFT
     │
     └──ลบ (เฉพาะ ADMIN, เฉพาะ DRAFT/PENDING/REVOKED)──> DELETED
```

- **ออกเลข**: กดทีละใบที่ปุ่ม "ออกเลข" ในแถวนั้น หรือเลือกหลายแถวแล้วกด **"ออกเลขที่เลือก"** (แทนปุ่ม "ออกเลขแบบชุด" เดิมที่ออกเลขทั้งกิจกรรมโดยเลือกเจาะจงไม่ได้)
- **แก้ไข**: เปลี่ยนชื่อ/สถานศึกษา/สถานะได้ทุกสถานะยกเว้น DELETED
- **เลือกหลายรายการ (Bulk)**: ติ๊กช่องหน้าตารางทีละแถว หรือติ๊กช่องบนหัวตารางเพื่อเลือกทั้งหมดที่แสดงอยู่ (นับเฉพาะแถวที่ผ่านการค้นหา/กรองในขณะนั้น) แถบเครื่องมือจะขึ้นมาให้กด **"ออกเลขที่เลือก"**, **"ยกเลิกที่เลือก"** (ใส่เหตุผลครั้งเดียวใช้กับทุกใบ) และ **"ลบที่เลือก"** (เฉพาะ ADMIN) — ระบบข้ามรายการที่สถานะไม่เข้าเงื่อนไขให้อัตโนมัติ และรายงานผลว่าสำเร็จ/ล้มเหลวกี่รายการ

- **ยกเลิก (Revoke)**: ทำได้เฉพาะใบสถานะ ISSUED ต้องระบุเหตุผลเสมอ ใบที่ถูกยกเลิกจะหายจากผลค้นหาสาธารณะทันที แต่ยังตรวจสอบผ่านหน้า Verify ได้ (จะแสดงว่าเป็นสถานะ REVOKED พร้อมเหตุผล)
- **ออกใหม่ (Reissue)**: ทำได้เฉพาะใบสถานะ REVOKED กลับไปเป็น DRAFT โดย**คงเลขที่เกียรติบัตรเดิมไว้เสมอ** ไม่กินเลขใหม่จากช่วงของกิจกรรม กด "ออกเลข" อีกครั้งเพื่อยืนยันการออกด้วยเลขเดิม — เลขจะเปลี่ยนก็ต่อเมื่อลบใบนั้นทิ้งแล้วสร้างใหม่เท่านั้น
- **ลบ**: ปุ่ม "ลบ" อยู่ในคอลัมน์การจัดการของทุกแถว (เห็นเฉพาะ ADMIN) กดได้เมื่อใบอยู่ในสถานะ DRAFT/PENDING/REVOKED ส่วนใบสถานะ ISSUED ปุ่มจะเป็นสีเทากดไม่ได้ ต้อง "ยกเลิก" ก่อนเพื่อรักษาหลักฐาน
- **ตัวอย่าง / ดาวน์โหลด PDF / JPEG**: ใช้ได้เฉพาะใบสถานะ ISSUED เท่านั้น

#### ขีดจำกัดต่อรอบ (สำคัญสำหรับงานจำนวนมาก)

- ระบบดำเนินการได้ **สูงสุด 25 รายการต่อ 1 รอบ** (ค่านี้กำหนดที่ `CertificateService.MAX_BULK_PER_ROUND` และเซิร์ฟเวอร์บังคับจริง) เพื่อไม่ให้ 1 คำสั่งชนลิมิต 6 นาทีของ Google Apps Script
- ถ้าเลือกเกิน 25 **หน้าเว็บจะแบ่งส่งให้เองอัตโนมัติ** ทีละ 25 จนครบ พร้อมแถบความคืบหน้า "รอบที่ x/y — เสร็จแล้ว n/N รายการ" และปุ่มหยุดหลังจบรอบปัจจุบัน
- **ห้ามปิด/รีเฟรชหน้าระหว่างทำงาน** เพราะตัวแบ่งรอบทำงานอยู่ที่หน้าเว็บ
- ถ้าหยุดกลางคัน (กดหยุดเอง หรือ session หมดอายุ) ระบบจะสรุปว่าทำสำเร็จไปแล้วกี่รายการและเหลืออีกกี่รายการ — เข้าสู่ระบบใหม่แล้วเลือกเฉพาะที่เหลือทำต่อได้เลย รายการที่สำเร็จไปแล้วจะไม่ถูกทำซ้ำและไม่กินเลขซ้ำ
- Session ของผู้ใช้มีอายุ 6 ชั่วโมงและ**ต่ออายุอัตโนมัติทุกครั้งที่มีการเรียกใช้งาน** จึงไม่หมดอายุกลางคันระหว่างทำงานต่อเนื่อง


### ดาวน์โหลดทะเบียนเป็น Excel

กดปุ่ม **"ดาวน์โหลด Excel"** จะได้ไฟล์ทะเบียนตามกิจกรรม/สถานะที่กรองอยู่ในขณะนั้น ตั้งชื่อไฟล์ตามกิจกรรมอัตโนมัติ

## 5. ตั้งค่า & Logs (ADMIN เท่านั้น)

### ตั้งค่าระบบ

แก้ชื่อระบบ หน่วยงาน, URL เว็บแอป, Drive Folder ID ของ Template/Temp, timezone — ค่าที่อ่อนไหว เช่น รหัสลับระบบและรหัสผ่านตั้งต้น จะไม่แสดงในหน้านี้เพื่อความปลอดภัย

### จัดการผู้ใช้งาน

สร้างบัญชี Admin/Staff ใหม่ กำหนดสิทธิ์ (role) และสถานะ (Active/Inactive) — ระบบบังคับให้มี ADMIN ที่ Active อย่างน้อย 1 บัญชีเสมอ ป้องกันการล็อกตัวเองออกจากระบบโดยไม่ตั้งใจ

### รายงานปัญหาจากสาธารณะ

เมื่อผู้ใช้ทั่วไปกด "แจ้งข้อมูลไม่ถูกต้อง" จากหน้าค้นหา รายการจะมาปรากฏที่นี่ ตรวจสอบแล้วกด **"ปิดเรื่อง"** เมื่อจัดการเสร็จ

### Audit Logs

บันทึกทุกการกระทำสำคัญในระบบ (สร้าง/แก้ไข/ลบกิจกรรม, ออกเลข, ยกเลิก, จัดการผู้ใช้ ฯลฯ) พร้อมผู้กระทำและเวลา กรองตาม action/entity/ผู้กระทำได้ และดูรายละเอียด "ก่อน-หลัง" ของแต่ละรายการได้ที่ลิงก์ "before/after"

## เคล็ดลับและข้อควรระวัง

- **การลบเทียบกับการยกเลิก**: ใบที่เคยออกเลขไปแล้วจะลบถาวรไม่ได้เด็ดขาด (ต้องยกเลิกแทน) เพื่อป้องกันข้อมูลเกียรติบัตรจริงหายไปโดยไม่มีหลักฐาน
- **การนำเข้าซ้ำ**: ระบบตรวจจากชื่อ+นามสกุล+โรงเรียนภายในกิจกรรมเดียวกัน หากมีคนชื่อซ้ำกันจริงในกิจกรรมเดียวกันแต่เป็นคนละคน ให้ระบุโรงเรียน/หน่วยงานให้ต่างกันเพื่อแยกแยะ หรือยืนยันนำเข้าซ้ำได้หากมั่นใจ
- **การกดปุ่มเดียวกันซ้ำเร็วๆ**: ระบบมีการจำกัดความถี่ (rate limit) ในการสร้างไฟล์ตัวอย่าง/ดาวน์โหลด หากกดถี่เกินไประบบจะแจ้งให้รอสักครู่
