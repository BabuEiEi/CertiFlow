2. เข้าสู่ระบบ

  1. เปิดหน้าเว็บ CertiFlow แล้วกดปุ่ม "Management Mode" มุมขวาบน
  2. กรอก userId และรหัสผ่านที่ได้รับจาก ADMIN
  3. หากพิมพ์รหัสผ่านผิดเกิน 5 ครั้งติดต่อกัน ระบบจะล็อกชั่วคราว 15 นาที
  4. เมื่อ login สำเร็จ ระบบจะจำสถานะไว้ในเบราว์เซอร์ — ปิดแท็บแล้วเปิดใหม่ยังคง login อยู่ จนกว่าจะกด "ออกจากระบบ" หรือ session หมดอายุ (6 ชั่วโมง)

3. ภาพรวม (Dashboard)

  • กิจกรรมทั้งหมด / ผู้เข้าร่วมทั้งหมด — จำนวนสะสมทุกกิจกรรม
  • ออกเกียรติบัตรแล้ว — จำนวนใบที่มีเลขที่แล้ว (สถานะ ISSUED)
  • รอดำเนินการ — ใบที่ยังไม่ได้ออกเลข (DRAFT/PENDING)
  • ถูกยกเลิก (Revoked) — ใบที่ถูกยกเลิกแล้ว
  • ตารางด้านล่างสรุปยอดแยกตามแต่ละกิจกรรม พร้อมสถานะกิจกรรม

4. จัดการกิจกรรม (Activities)

สร้างกิจกรรมใหม่

กดปุ่ม "+ สร้างกิจกรรมใหม่" แล้วกรอกชื่อกิจกรรม ผู้จัด หน่วยงานที่ออก วันที่ (เลือกจากปฏิทิน) และตั้งค่ารูปแบบเลขที่เกียรติบัตร เช่น เลขที่ สพม.พลอต ๐๐๐๑/๒๕๖๙

ช่อง "ด้านการอบรม" เลือกได้ว่า ไม่มี (เกียรติบัตรไม่ระบุด้านการอบรม — ค่าเริ่มต้น) หรือ มี ซึ่งจะเปิดกล่องข้อความให้พิมพ์ค่าที่จะใช้แทน {{type}} เมื่อไฟล์นำเข้าไม่ได้ระบุด้านการอบรมของคนนั้นไว้

สำคัญ: ระบบออกเลขไม่ซ้ำกันเสมอ ห้ามลดค่า "เลขเริ่มต้น" ให้ต่ำกว่าที่เคยใช้ไปแล้ว (ระบบจะไม่อนุญาตให้บันทึก) และถ้าออกเลขจนถึง "เลขสิ้นสุด" แล้ว ต้องแก้ไขกิจกรรมเพื่อขยายเลขสิ้นสุดก่อนออกเพิ่ม
นอกจากนี้ ช่วง "เลขเริ่มต้น-เลขสิ้นสุด" ของกิจกรรมที่ใช้รูปแบบเลขเดียวกัน (ข้อความนำหน้า + prefix + ตัวคั่น + ปี ตรงกันทั้งหมด) ห้ามทับซ้อนกัน ระบบจะไม่ให้บันทึกและบอกว่าไปชนกับกิจกรรมใด เช่น กิจกรรมที่ 1 ใช้ 1111-1220 กิจกรรมที่ 2 ใช้ 1331-1351 บันทึกได้ (ไม่จำเป็นต้องต่อเนื่องกัน) แต่ถ้ากิจกรรมที่ 2 ใช้ 1200-1300 จะถูกปฏิเสธ

เตรียม Google Slides Template

  1. สร้างไฟล์ Google Slides ที่มีสไลด์หลักเพียง 1 หน้า
  2. ใส่ข้อความ {{name}} ตรงตำแหน่งชื่อผู้รับ และ {{certNo}} ตรงตำแหน่งเลขที่เกียรติบัตร (อย่างละ 1 ตำแหน่งเท่านั้น)
  3. ใส่เพิ่มได้แบบไม่บังคับ: {{office}} = สถานศึกษา/หน่วยงานของผู้รับ และ {{type}} = ด้านการอบรม (เช่น ด้านการอ่าน, ด้านคณิตศาสตร์) อย่างละไม่เกิน 1 ตำแหน่ง — ถ้าเทมเพลตไม่มี 2 ตัวนี้ก็ใช้งานได้ตามปกติ
  4. ต้องการฝัง QR Code สำหรับตรวจสอบเกียรติบัตร (ลิงก์หน้า Verify) ลงในไฟล์ด้วย ให้วาดกล่องข้อความสี่เหลี่ยมในตำแหน่งที่ต้องการ พิมพ์ {{qr}} ลงไป แล้วปรับขนาดกล่องให้เป็นสี่เหลี่ยมจัตุรัสตามขนาด QR ที่ต้องการ ระบบจะแทนที่กล่องนี้ด้วยรูป QR ให้อัตโนมัติตอนออกเลข/ดาวน์โหลด (ไม่บังคับ — ถ้าไม่ใส่ก็จะไม่มี QR บนใบ)
  5. คัดลอก Template ID จาก URL ของไฟล์ (ระหว่าง /d/ กับ /edit) มาใส่ในฟอร์ม
  6. กด "ตรวจ Template" เพื่อเช็คว่าพบ placeholder ครบถูกต้อง
  7. กด "Preview" เพื่อดูตัวอย่างหน้าตาจริง (อาจใช้เวลา 3-8 วินาที)

แก้ไข / ลบกิจกรรม

แก้ไขได้แม้มีเกียรติบัตรออกไปแล้ว (ยกเว้นลดเลขเริ่มต้น) ส่วนการลบทำได้เฉพาะ ADMIN เท่านั้น — กิจกรรมที่ยังไม่มีผู้เข้าร่วม/เกียรติบัตรผูกอยู่ลบได้ทันที ส่วนกิจกรรมที่ปิดแล้ว (CLOSED) ลบได้เช่นกันแต่ระบบจะลบผู้เข้าร่วมและเกียรติบัตรที่ผูกอยู่ทั้งหมดไปด้วย (กู้คืนไม่ได้) กิจกรรมที่ยังไม่ปิดและมีข้อมูลอ้างอิงจะลบไม่ได้ ต้องเปลี่ยนสถานะเป็น CLOSED ก่อน

5. นำเข้ารายชื่อ (Participants)

มี 2 วิธี: ปุ่ม "+ เพิ่มทีละรายการ" สำหรับกรอกทีละคน และปุ่ม "+ นำเข้าจากไฟล์ Excel/CSV" สำหรับนำเข้าทีละหลายรายการ

วิธีที่ 1 — เพิ่มทีละรายการ

  1. กดปุ่ม "+ เพิ่มทีละรายการ" เลือกกิจกรรม แล้วกรอก คำนำหน้า / ชื่อ / นามสกุล / สถานศึกษา / ด้านการอบรม / สถานะ (ชื่อและนามสกุลบังคับกรอก)
  2. ถ้าชื่อนี้ซ้ำกับที่มีอยู่แล้ว ระบบจะเตือนและให้ติ๊กยืนยันก่อนบันทึกอีกครั้ง
  3. ติ๊ก "บันทึกแล้วเปิดฟอร์มค้างไว้เพื่อเพิ่มรายถัดไป" ถ้าต้องการกรอกต่อหลายคน (ระบบจะคงกิจกรรม/สถานศึกษา/ด้านการอบรมเดิมไว้ให้)

วิธีที่ 2 — นำเข้าจากไฟล์ Excel/CSV

  1. กดปุ่ม "+ นำเข้าจากไฟล์ Excel/CSV" แล้วเลือกกิจกรรม
  2. อัปโหลดไฟล์ CSV/XLSX (กด "ดาวน์โหลด Template Excel" ก่อนเพื่อได้หัวคอลัมน์ที่ถูกต้อง) หรือวางข้อความคั่นด้วยจุลภาค/Tab ตามลำดับ คำนำหน้า, ชื่อ, นามสกุล, โรงเรียน/หน่วยงาน, ด้านการอบรม, สถานะ
  3. กด "ตรวจสอบข้อมูลก่อนนำเข้า (Validate)" — ระบบแยกแถวเป็น ถูกต้อง / อาจซ้ำ / ผิดพลาด และแสดงทั้งสถานศึกษาและด้านการอบรมของทุกแถวให้ตรวจก่อนบันทึก
  4. หากมีรายการ "อาจซ้ำ" และต้องการนำเข้าจริง ให้ติ๊ก "ยืนยันนำเข้ารายชื่อที่อาจซ้ำซ้อนด้วย"
  5. กด "ยืนยันการบันทึกนำเข้า" (นำเข้าได้สูงสุด 5,000 แถวต่อครั้ง)

แต่ละแถวที่นำเข้าสำเร็จจะถูกสร้างเป็นผู้เข้าร่วม + เกียรติบัตร (สถานะ DRAFT รอออกเลข) โดยอัตโนมัติ แก้ไขข้อมูลรายคนได้จากปุ่ม "แก้ไข" ที่แถวนั้นในตาราง

ลบผู้เข้าร่วม (ADMIN และ STAFF ทำได้): ติ๊กเลือกทีละคนหรือติ๊กช่องหัวตารางเพื่อเลือกทั้งหมด แล้วกด "ลบที่เลือก" หรือกด "ลบ" ที่แถวนั้น/ในหน้าต่างแก้ไข — ต้องระบุเหตุผลก่อนยืนยันทุกครั้ง ระบบจะลบเกียรติบัตรที่ผูกกับคนนั้นไปด้วย แต่ถ้าเกียรติบัตรออกเลขแล้ว (ISSUED) จะลบไม่ได้ ต้อง "ยกเลิก" เกียรติบัตรที่หน้ารายการเกียรติบัตรก่อน

คอลัมน์ โรงเรียน/หน่วยงาน จะถูกพิมพ์ลงเกียรติบัตรที่ {{office}} และคอลัมน์ ด้านการอบรม ที่ {{type}} — เว้นช่องด้านการอบรมว่างได้ ระบบจะใช้ค่าที่ตั้งไว้ในหน้ากิจกรรมแทน (ถ้ากิจกรรมเลือก "ไม่มี" ก็ปล่อยว่างทั้งคอลัมน์ได้เลย) หากตารางตรวจสอบขึ้นว่าสถานศึกษาเป็น "— ว่าง —" แปลว่าหัวคอลัมน์ในไฟล์จับคู่ไม่ติด ให้ตั้งชื่อหัวคอลัมน์ให้มีคำว่า โรงเรียน / สถานศึกษา / หน่วยงาน หรือ school

6. รายการเกียรติบัตร (Certificates Registry)

ทะเบียนกลางของเกียรติบัตรทุกใบ กรองได้ตามกิจกรรม/สถานะ และค้นหาในตารางได้

DRAFT/PENDING --ออกเลข--> ISSUED --ยกเลิก (ระบุเหตุผล)--> REVOKED --ออกใหม่ (คงเลขเดิม)--> DRAFT | +--ลบ (เฉพาะ ADMIN, เฉพาะ DRAFT/PENDING/REVOKED)--> DELETED
  • ออกเลข: กดทีละใบที่ปุ่ม "ออกเลข" ในแถวนั้น หรือใช้การเลือกหลายรายการแล้วกด "ออกเลขที่เลือก"
  • เลือกหลายรายการ: ติ๊กช่องหน้าตาราง (หรือติ๊กช่องบนหัวตารางเพื่อเลือกทั้งหมดที่แสดงอยู่) จะมีแถบเครื่องมือขึ้นมาให้ "ออกเลขที่เลือก" / "ยกเลิกที่เลือก" / "ลบที่เลือก" (ลบเฉพาะ ADMIN) — ระบบจะข้ามรายการที่สถานะไม่เข้าเงื่อนไขให้อัตโนมัติ และรายงานผลว่าสำเร็จ/ล้มเหลวกี่รายการ
  • ทำได้สูงสุด 25 รายการต่อรอบ: ถ้าเลือกมากกว่านั้น ระบบจะแบ่งส่งเป็นหลายรอบให้เองโดยอัตโนมัติ (รอบละ 25) พร้อมแถบความคืบหน้า "รอบที่ x/y" และปุ่มหยุดหลังจบรอบปัจจุบัน — ห้ามปิดหรือรีเฟรชหน้าระหว่างทำงาน ถ้าหยุดกลางคันหรือ session หมดอายุ ระบบจะบอกว่าทำไปแล้วกี่รายการและเหลืออีกกี่รายการ ให้เข้าสู่ระบบใหม่แล้วเลือกเฉพาะรายการที่เหลือทำต่อได้ทันที (รายการที่สำเร็จไปแล้วจะไม่ถูกทำซ้ำ)
  • ยกเลิก (Revoke): ทำได้เฉพาะใบสถานะ ISSUED ต้องระบุเหตุผลเสมอ ใบที่ถูกยกเลิกจะหายจากผลค้นหาสาธารณะทันที แต่ยังตรวจสอบผ่านหน้า Verify ได้
  • ออกใหม่ (Reissue): ทำได้เฉพาะใบสถานะ REVOKED กลับไปเป็น DRAFT โดยคงเลขที่เกียรติบัตรเดิมไว้เสมอ ไม่มีการกินเลขใหม่จากช่วงของกิจกรรม กด "ออกเลข" อีกครั้งเพื่อยืนยันการออกด้วยเลขเดิม (เลขจะเปลี่ยนก็ต่อเมื่อลบใบนั้นทิ้งแล้วสร้างใหม่เท่านั้น)
  • ลบ: ปุ่ม "ลบ" อยู่ในคอลัมน์การจัดการของทุกแถว (เห็นเฉพาะ ADMIN) กดได้เมื่อใบอยู่ในสถานะ DRAFT/PENDING/REVOKED ส่วนใบสถานะ ISSUED ปุ่มจะเป็นสีเทากดไม่ได้ ต้อง "ยกเลิก" ก่อน
  • ตัวอย่าง / ดาวน์โหลด PDF / JPEG / QR: ใช้ได้เฉพาะใบสถานะ ISSUED เท่านั้น
  • ดาวน์โหลด Excel: ส่งออกทะเบียนตามกิจกรรม/สถานะที่กรองอยู่ในขณะนั้นเป็นไฟล์ .xlsx

7. ตั้งค่า & Logs (ADMIN เท่านั้น)

  • ตั้งค่าระบบ: ชื่อระบบ หน่วยงาน, URL เว็บแอป, Drive Folder ID, timezone — ค่าที่อ่อนไหวจะไม่แสดงในหน้านี้เพื่อความปลอดภัย
  • จัดการผู้ใช้งาน: สร้างบัญชี Admin/Staff กำหนดสิทธิ์และสถานะ — ระบบบังคับให้มี ADMIN ที่ Active อย่างน้อย 1 บัญชีเสมอ
  • รายงานปัญหาจากสาธารณะ: รายการที่ผู้ใช้ทั่วไปแจ้ง "ข้อมูลไม่ถูกต้อง" จะมาปรากฏที่นี่ กด "ปิดเรื่อง" เมื่อจัดการเสร็จ
  • Audit Logs: บันทึกทุกการกระทำสำคัญพร้อมผู้กระทำและเวลา กรองได้ และดูรายละเอียด "ก่อน-หลัง" ของแต่ละรายการได้

8. เคล็ดลับและข้อควรระวัง

  • ใบที่เคยออกเลขไปแล้วจะลบถาวรไม่ได้เด็ดขาด (ต้องยกเลิกแทน) เพื่อป้องกันข้อมูลเกียรติบัตรจริงหายไปโดยไม่มีหลักฐาน
  • การนำเข้าซ้ำตรวจจากชื่อ+นามสกุล+โรงเรียนภายในกิจกรรมเดียวกัน หากมีคนชื่อซ้ำกันจริงแต่เป็นคนละคน ให้ระบุโรงเรียน/หน่วยงานให้ต่างกัน หรือยืนยันนำเข้าซ้ำได้หากมั่นใจ
  • การสร้างไฟล์ตัวอย่าง/ดาวน์โหลดมีการจำกัดความถี่ (rate limit) หากกดถี่เกินไประบบจะแจ้งให้รอสักครู่
